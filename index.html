三步开始使用

从装包到让 AI 干活，跟着新手教程约 20 分钟

1

下载并安装

下载 APK 后直接安装。若系统提示「未知来源」，在设置中允许浏览器或文件管理器安装应用即可。

2

配置模型 API

打开设置 → 模型 API，填入服务商地址与 Key。支持 OpenAI、Responses、Anthropic 三条协议与主流中转。

3

说第一句话

新建会话，把资料丢给它、把项目交给它。首次使用建议先看新手教程，20 分钟走完全程。

安装提示：v2.6.12 起应用包名变更为 io.github.jiusis.shiyi，与旧版 com.shiyi.agent 是两个独立应用：安装新版后旧版及其数据仍在，数据（API Key、模型、会话、记忆）需手动迁移或在新版重新配置，旧版可自行保留或卸载。同包名后续版本请直接 adb install -r 覆盖升级、数据全部保留，请勿先卸载再安装（卸载会清空应用数据）。正式包签名指纹 SHA-256：5a3936d1b4744ed3901864cf5f507d048a5620971230e1945d54dd16f555350b。

它能做什么

大语言模型 + 长期记忆 + 项目管理 + 内置终端 + 技能系统

智能对话

三条协议自由切换，思考档位随模型自动匹配，流式输出与思考链全程可见。

长期记忆

跨会话记住你的偏好、项目与约定，越用越懂你；上下文压缩随时可手动触发。

项目与文件

按项目组织会话与资料，AI 直接读写项目文件，改动过程清晰可回溯。

内置终端

Android 内嵌 Alpine 环境，Windows 走本机 WSL / Git Bash / PowerShell，命令行随手可开。

技能系统

把重复流程沉淀成可安装的技能 zip，一次封装、处处复用。

群聊协作

多个 Agent 按公司结构组队：分角色、定人设、层级汇报，一个项目多人分工。

最近更新

完整记录见仓库 CHANGELOG

v2.6.12当前版本2026-10-25
  • 应用包名升级为 io.github.jiusis.shiyi：与旧版（com.shiyi.agent）是两个独立应用，安装新版后旧版及数据仍在，数据需手动迁移或在新版重新配置。
  • 首页底栏换成液态玻璃悬浮胶囊：更贴合内容区、键盘弹起时自动让位，不再垫出空白。
  • 修复桌面端模型同步的一处编译问题。
  • 版本号与包信息对齐发布规范（2.6.12 / versionCode 37）。
v2.6.11上一版2026-10-16
  • 模型输出不再被人为上限截断：默认不限制输出长度，四项上限均可在设置中自行收紧，老配置自动迁移。
  • 网络断连每轮自动重试：修掉按 UTF-16 截断切碎 emoji 导致的非法请求体，连接稳定性大幅改善。
  • 首字延迟降低约 3 秒：活人感数据并行拉取且限时，慢就跳过，绝不拖住请求。
  • 群聊改成真正的层级行动：一批全员并行、整批汇报完才进下一批，群成员拿到完整工具集。
